# Security

The permission card records intended boundaries. It does not enforce access controls, sandbox an agent, or replace a security review.

## Keep private data out of this repository

Do not commit real credentials, tokens, customer records, private URLs, internal file paths, confidential prompts, or incident details. Use `example.com`, fictional values, and redacted screenshots in examples.

If you find a vulnerability in the schema, validator, or workflow, use GitHub's private vulnerability reporting for this repository when it is available. Do not publish working exploit details in an issue.

The repository does not need telemetry, remote calls, or an executable agent. A change that adds any of them needs a separate security review before it can be merged.
