# AI Agent Permission Card

## goal

What verifiable result should this run produce?

## may_read

- List each allowed URL, file, account, or data source.

## may_write

- List each allowed output or write target. Leave no implied access.

## ask_before

- List the actions that require human approval before a tool runs.

## stop_if

- List ambiguity, access, data, and retry conditions that stop the run.

## show_me

- List the URLs, files, records, tests, or logs that prove what happened.
